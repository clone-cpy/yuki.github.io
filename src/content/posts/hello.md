换了个新主题，也换了一种记录方式。

这个博客现在跑在 GitHub Pages 上：写作在浏览器里完成，图片上传后自动进仓库，提交之后 GitHub Actions 负责构建和发布。不再需要开着一台电脑挂着后台。

## 为什么又开一个博客

之前也搭过几次，最后都荒了。原因大概不是没时间，而是**写一篇文章的成本太高**：打开编辑器、调格式、传图、部署，一套流程下来，想说的话已经凉了。

这次的目标很简单：把「写」这一步的成本降到最低。

- 打开网页就能写
- 图片拖进去就上传
- 点提交就发布，剩下的交给 CI

## 这里会写什么

主要是三类东西：

1. 技术笔记：踩过的坑、读过的源码、做过的取舍
2. 设计与审美：排版、留白、动效这些说不清但看得见的东西
3. 随笔：一些还不足以成文的想法

如果你是从搜索引擎找过来的，希望某一篇恰好能帮到你。

> 写作是另一种形式的思考。把想法写清楚的过程，本身就是一次整理。
